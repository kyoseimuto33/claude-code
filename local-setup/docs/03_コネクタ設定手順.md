# 03. コネクタ（MCP）設定手順

## 結論: 基本は設定不要

claude.ai で接続したコネクタ（https://claude.ai/customize/connectors）は、
**ローカルの Claude Code に claude.ai アカウントでログインしていれば自動で使えます**。
（公式: https://code.claude.com/docs/en/mcp の「Use MCP servers from claude.ai」）

接続情報（OAuth トークン）は claude.ai 側に保存されているため、zip にはコネクタの認証情報は入っていませんし、入れる必要もありません。

## 確認方法

1. `claude` を起動
2. `/mcp` と入力
3. 「claude.ai」の区分に以下が並んでいれば OK

| コネクタ | クラウドでの状態 | ローカルでやること |
|---|---|---|
| Gmail | 接続済み | なし |
| Google Calendar | 接続済み | なし |
| Google Drive | 接続済み | なし |
| Google Sheets | 接続済み | なし |
| Google Slides | 接続済み | なし |
| Slack | 接続済み | なし |
| Ahrefs | 接続済み | なし |
| higgsfield | 接続済み | なし |
| Claude Docs | Anthropic 提供 | なし |
| Canva | 未接続 | 使う場合のみ claude.ai/customize/connectors で接続 |
| Supermetrics Marketing Analytics | 接続未完了 | 同上（接続を完了させる） |
| Windsor.ai | 接続未完了 | 同上 |

一度もサインインしていないコネクタは `/mcp` の末尾「Show unused connectors」の中に折りたたまれています。

## 表示されないとき

| 症状 | 原因と対処 |
|---|---|
| claude.ai の区分自体が出ない | 認証方法が claude.ai 以外。`/status` で確認。`ANTHROPIC_API_KEY` / `ANTHROPIC_AUTH_TOKEN` / `CLAUDE_CODE_OAUTH_TOKEN` 環境変数や `apiKeyHelper` 設定を外して `/login` し直す |
| 特定のコネクタだけ無い | claude.ai 側で未接続。claude.ai/customize/connectors で接続 → Claude Code を再起動 |
| `session token rejected` と出る | `/login` でログインし直す（コネクタの再認可では直らない） |
| 一時的に出ない | 起動時の通信エラー。Claude Code を再起動 |

## コネクタのツール名（許可設定・スクリプトで使う）

ローカルでは claude.ai コネクタのサーバー名は「claude.ai Slack」のように表示され、
ツール名は `mcp__claude_ai_<コネクタ名>__<ツール名>` の形になります（記号は `_` に置換）。

- 例: Slack 送信 → `mcp__claude_ai_Slack__slack_send_message`
- サーバー単位でまとめて許可: `mcp__claude_ai_Slack`

`routines/run_routine.*` はこの名前で Slack を許可しています。`/mcp` で表示される名前が異なる場合は
スクリプト内の `mcp__claude_ai_Slack` を実際の名前に合わせてください。

## 特定のコネクタをローカルでは使わない場合

`/mcp` で該当コネクタを選んで無効化できます。設定ファイルで恒久的に止める場合は `~/.claude/settings.json` に:
```json
{ "deniedMcpServers": [ { "serverName": "claude.ai higgsfield" } ] }
```

## クラウド専用だったツールの代替

| クラウド | ローカルでの代替 |
|---|---|
| GitHub ツール（PR 作成・コメント等） | `git` コマンド ＋ GitHub CLI（`gh auth login`）。Claude に「PR を作って」と頼めば `gh` を使います |
| Claude Code Remote（セッション・ルーティン管理） | ルーティン: `/schedule`（`/routines`）コマンド、または claude.ai/code/routines。セッション引き継ぎ: `claude --teleport` |

## （参考）コネクタではなく MCP サーバーを直接追加する場合

claude.ai を経由せず、ローカルだけで MCP サーバーを使いたい場合:
```bash
claude mcp add --transport http <名前> <MCPサーバーのURL>            # 自分だけ（~/.claude.json）
claude mcp add --scope project --transport http <名前> <URL>          # リポジトリで共有（.mcp.json）
```
URL は各サービスの公式ドキュメントに記載されたものを使用してください。通常は claude.ai コネクタで足ります。
