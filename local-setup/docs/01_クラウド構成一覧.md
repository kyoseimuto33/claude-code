2026-10-07 時点で、claude.ai のクラウド環境（Claude Code on the web / Routines / Connectors）に
設定・接続・構築されているものの一覧です。ローカルへ持っていく必要があるか（＝移行区分）も併記しています。

移行区分の凡例:
- **自動** … claude.ai アカウントでローカルの Claude Code にログインするだけで使える。作業不要
- **同梱** … このパッケージに入っている。セットアップスクリプトで配置される
- **要設定** … 手作業が必要（各手順書を参照）
- **クラウド専用** … ローカルでは不要、または代替手段で置き換える

## 6. クラウド専用で移行不要なもの

- エージェントプロキシ（`HTTPS_PROXY`、CA バンドル）… クラウドの通信制御用。ローカルは不要
- クラウドの Stop フック（未コミット変更チェック等）… クラウド基盤のもの。ローカルは不要
- Artifact 公開機能 … ローカルの Claude Code でも claude.ai ログイン時は利用可（設定不要）
