# 04. シークレット（認証情報）の管理

## このパッケージの方針

クラウドのルーティンのうち2つは、**API の認証情報がプロンプト本文に平文で書かれていました**。
この zip はリポジトリ（GitHub）にも保存されるため、**実際の値は一切含めず**、プレースホルダ（`__XXX__`）に置き換えています。

ローカルでは、パッケージ直下の `.env` ファイル（`config/.env.example` から作成）に値を書きます。
`.env` は作業リポジトリ（`repo/`）の**外**に置くので Git にコミットされません。加えて、リポジトリ内に `.env` を置いた場合に備えて `.gitignore` に追記し、`.claude/settings.json` で Claude による `.env` の読み取りを拒否しています。

## 必要なシークレット一覧

| 変数名 | 用途 | 使うルーティン | 値の入手先 |
|---|---|---|---|
| `SHOPIFY_READ_ORDERS_CLIENT_ID` | Shopify 注文読み取り用アプリの Client ID | archi-dog 人気商品ランキング | ① 下記「クラウドから値を写す」<br>② Shopify 管理画面 → 設定 → アプリと販売チャネル → アプリを開発 → 該当アプリ → API 認証情報 |
| `SHOPIFY_READ_ORDERS_CLIENT_SECRET` | 同 Client Secret（`shpss_` で始まる） | 同上 | 同上 |
| `SHOPIFY_WRITE_CLIENT_ID` | Shopify 商品・コレクション書き込み用アプリの Client ID | 同上 | 同上 |
| `SHOPIFY_WRITE_CLIENT_SECRET` | 同 Client Secret | 同上 | 同上 |
| `FLUMO_API_BASIC_AUTH` | flumo-api-server.com 管理 API の Basic 認証値（`Authorization: Basic` の後ろの base64 文字列） | SEO Pipeline - Monthly Auto | ① 下記「クラウドから値を写す」<br>② API の管理者 |
| `AI_TREND_SLACK_CHANNEL_ID` | AIトレンド配信先 Slack チャンネル ID（任意） | Weekly ai trend | Slack でチャンネル名を右クリック → リンクをコピー（末尾の `C...`） |
| `SEO_TREND_SLACK_CHANNEL_ID` | SEOトレンド配信先 Slack チャンネル ID（任意） | Weekly seo trend | 同上 |

Slack のチャンネル ID は未設定（プレースホルダのまま）でも動きます。その場合はクラウド版と同じく本人への DM（`U05C0044HGQ`）に送られます。

## クラウドから値を写す手順

1. https://claude.ai/code/routines を開く
2. 「archi-dog 人気商品ランキング 週次更新」→ 編集
3. 指示（プロンプト）内の `READ_ORDERS_CLIENT_ID = "..."` などの値を、`.env` の対応する行にコピー
4. 「SEO Pipeline - Monthly Auto」→ 編集 → `Authorization: Basic ...` の `...` 部分を `FLUMO_API_BASIC_AUTH=` にコピー

## `.env` の書き方

```dotenv
SHOPIFY_READ_ORDERS_CLIENT_ID=ここに値
SHOPIFY_READ_ORDERS_CLIENT_SECRET=ここに値
```
- `=` の前後にスペースを入れない
- 値に引用符は不要
- macOS/Linux では `chmod 600 .env`（setup.sh が自動で実施）

## ⚠️ 推奨: 移行を機に再発行（ローテーション）

これらの値はルーティンのプロンプト本文に平文で入っており、各実行のセッションログにも残っています。
ローカル移行のタイミングで以下を推奨します。

1. Shopify の2つのカスタムアプリの Client Secret を再発行し、新しい値を `.env` に設定
2. flumo API の Basic 認証パスワードを変更し、新しい値を `.env` に設定
3. **クラウドのルーティンも引き続き使う場合**は、プロンプトに直書きせず、クラウド環境の「環境変数」
   （claude.ai/code の環境メニュー → Edit → Environment variables）に同じ変数名で登録し、
   プロンプトからは `$SHOPIFY_WRITE_CLIENT_SECRET` のように参照する形へ書き換える
   （このパッケージの `routines/prompts/*.md` と `routines/scripts/popularity_score.py` がその形になっています）
4. ルーティンをローカルに完全移行する場合は、クラウド側のルーティンを無効化または削除する（二重実行防止。05 参照）

## やってはいけないこと

- `.env` を zip に入れて人に渡す / Slack・メールに貼る / Git にコミットする
- プロンプトや CLAUDE.md に値を直書きする
- Claude との会話に値を貼り付ける（会話ログに残ります）
