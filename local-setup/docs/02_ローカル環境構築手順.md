# 02. ローカル環境構築手順

所要時間の目安: 15〜20分。Mac / Windows / Linux 共通の流れです。

## 前提

| 必要なもの | 確認コマンド | 入手先 |
|---|---|---|
| claude.ai アカウント（クラウドで使っているのと同じもの） | — | — |
| Git | `git --version` | https://git-scm.com/ （Windows は Git for Windows。Git Bash も入る） |
| Python 3.9 以上 | `python3 --version`（Windows は `python --version`） | https://www.python.org/ |
| Claude Code（CLI） | `claude --version` | 下記 |

動作要件（公式）: macOS 13+ / Windows 10 1809+ / Ubuntu 20.04+ / Debian 10+、メモリ 4GB 以上。

## 手順 1. Claude Code をインストール

**macOS / Linux / WSL**
```bash
curl -fsSL https://claude.ai/install.sh | bash
```

**Windows（PowerShell）**
```powershell
irm https://claude.ai/install.ps1 | iex
```

（npm でも可: `npm install -g @anthropic-ai/claude-code`。Node.js 22 以上が必要）
公式手順: https://code.claude.com/docs/en/setup

> デスクトップアプリ（Claude for Mac/Windows）の「Code」タブでも同じことができます。CLI に慣れていなければそちらでも可。

## 手順 2. パッケージを展開してセットアップスクリプトを実行

zip を任意の場所（例: `~/claude-local-setup`、`C:\Users\<名前>\claude-local-setup`）に展開し、そのフォルダで:

**macOS / Linux / WSL**
```bash
cd ~/claude-local-setup
bash scripts/setup.sh
```

**Windows（PowerShell）**
```powershell
cd $HOME\claude-local-setup
powershell -ExecutionPolicy Bypass -File .\scripts\setup.ps1
```

スクリプトが行うこと:
1. git / python / claude の有無を確認
2. `repo/` に GitHub リポジトリを clone（作業ブランチ `claude/great-mccarthy-f4v1v3` をチェックアウト）
   - clone できない場合（GitHub 未ログイン等）は同梱の `project/` をコピー
3. `repo/` に `CLAUDE.md`・`.claude/settings.json`・`requirements.txt` を配置し、`.gitignore` に `.env` 等を追記
4. `openpyxl` をインストール
5. `.env` をテンプレートから作成（既にあれば上書きしない）
6. **動作確認**: `build_simulation.py` を実行し、クラウドで検証済みの結果（保守 ¥679,294 / 標準 ¥1,116,879 / 強気 ¥1,641,419）と一致するか判定

最後に「検証結果: すべて一致」と出れば成功です。

### 手動でやる場合
```bash
git clone https://github.com/kyoseimuto33/claude-code.git repo
cd repo && git checkout claude/great-mccarthy-f4v1v3
mkdir -p .claude
cp ../config/claude/CLAUDE.md . && cp ../config/claude/settings.json .claude/ && cp ../config/requirements.txt .
python3 -m pip install -r requirements.txt
python3 build_simulation.py
```

## 手順 3. Claude Code にログイン

```bash
cd ~/claude-local-setup/repo
claude
```
初回起動時にログイン方法を聞かれるので **「Claude アカウント（claude.ai のサブスクリプション）」** を選び、
クラウドで使っているのと同じアカウントでログインします（後から変える場合は `/login`）。

> ⚠️ `ANTHROPIC_API_KEY` 環境変数が設定されていると API キー認証が優先され、claude.ai のコネクタが読み込まれません。
> `/status` で認証方法が claude.ai になっているか確認してください。

## 手順 4. 確認

Claude Code の中で:

| 入力 | 期待される結果 |
|---|---|
| `/status` | ログイン方法が claude.ai アカウントになっている |
| `/mcp` | Gmail / Google Drive / Slack / Ahrefs などが「claude.ai」由来として一覧に出る（03 参照） |
| `/memory` | プロジェクトの `CLAUDE.md` が読み込まれている |
| 「build_simulation.py を実行して結果を教えて」 | 許可確認なしで実行され（`.claude/settings.json` で許可済み）、3シナリオの結果が出る |

## 手順 5.（任意）シミュレーターをブラウザで開く

`repo/index.html` をダブルクリックで開くだけで動きます（外部通信なし）。

## 配置後のフォルダ構成

```
claude-local-setup/
├── .env                  ← シークレット（自分で記入。共有・コミット禁止）
├── repo/                 ← 作業用リポジトリ（ここで `claude` を起動）
│   ├── CLAUDE.md
│   ├── .claude/settings.json
│   ├── build_simulation.py / index.html / *.xlsx / README.md
│   └── requirements.txt
├── routines/             ← 定期実行（05 参照）
├── outputs/              ← 週次トレンド資料の保存先（初回実行時に作成）
└── ...
```

## クラウドとローカルの使い分け

- クラウドのセッションをローカルに引き継ぐ: `claude --teleport`（一覧から選択）。そのセッションの会話とブランチがローカルに来ます
  （作業ツリーがクリーンであること、同じアカウントでログインしていることが条件）
- ローカルで作った変更は `git push` すれば、クラウドのセッションからも同じブランチで続きができます
