# クラウドサイン送付用情報

Fulmo のクラウドサインはライトプランで、Web API は使えない（API はスタンダードプラン以上）。送付は担当者がクラウドサインの画面で行う。このスキルは、担当者がそのまま写せる送付用情報を、ドラフト・レビュー依頼と同時に出す。送信はしない。

## 情報の取り方

| 項目 | 取り方 |
|---|---|
| 顧客番号（ID） | 顧客管理シート（`templates.md` の「原本の探し方」）の「顧客番号」 |
| 契約者名（正式名称） | 同シートの「契約書会社名（正式名称）」。原契約・過去の覚書の表記と一致するか確かめる（個人の場合は氏名） |
| 先方担当者の氏名 | 同シートの「契約書氏名（フルネーム）」 |
| 先方担当者のメールアドレス | 同シートの「メールアドレス」 |
| 書類名 | 先方に渡す Word のファイル名から拡張子を除いたもの（例: 変更覚書_〇〇御中） |
| 添付ファイル | 手塚さんの OK が出た最終版を PDF にしたもの（`soffice --headless --convert-to pdf`）。【●】が残っていないこと、改ページ・表が崩れていないことを確かめる |
| 送信時のメッセージ | 任意。短くし、外部向けの文面として yomiyasu で推敲する。書面にない約束や説明を足さない |

宛先の照合: シートの値は契約時点の情報なので、前回の締結時の宛先（クラウドサインの締結完了メール、過去の覚書の送付記録）と照合する。食い違う、空欄、複数の候補がある場合は推測で選ばず、「要確認」として確認先を書く。

## 出力する形

ドラフトとレビュー依頼の後に、次をそのまま出す（コピーしやすいようコードブロックで）。

```
■ クラウドサイン送付用情報
ログインURL: https://www.cloudsign.jp/

顧客番号（ID）: C00000xx
契約者名（正式名称）: 〇〇株式会社
先方担当者（氏名）: 〇〇 〇〇
メールアドレス: xxx@example.co.jp

書類名: 変更覚書_〇〇御中
添付ファイル: 変更覚書_〇〇御中.pdf（手塚さんの OK 後の最終版を PDF にして添付。保存先: <場所>）
送信時のメッセージ（任意）: <推敲済みの短い文面>

確認状況: 宛先の出典（顧客管理シートの行）／前回締結時の宛先との照合結果／要確認の点
送付の流れ: ログイン → 書類を作成 → PDF を追加 → 宛先（上の氏名・メールアドレス）を追加 → 内容を確認して送信
```

画面の操作で迷ったら、クラウドサインのヘルプセンター（https://help.cloudsign.jp/ja/ の「書類を送信する」）を案内する。
