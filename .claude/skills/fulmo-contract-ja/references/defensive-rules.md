# Fulmo を守るための判断基準

出典: Slack での手塚さんの方針、過去に作成・締結した覚書と合意書、紛争・訴訟になった案件の振り返り（2025〜2026年）。

## 1. こちらから言及しない

基本の考え方は「契約書を読めば分かる不利益や、棚上げにしている事項は、こちらから書かない・持ち出さない」。書かないことで生じる余地は、相手から言われたときに交渉の材料として使う（例: 月額利用料との相殺で応じる）。

書面に入れないもの（相手から求められていなければ触れない）:
- 棚上げにしている金銭（譲渡金、精算金、未請求の費用など）。解約合意書では「契約解除と、権利関係がすべて Fulmo に移ること」だけを書く。原契約に支払条項があり消したいときは「譲渡金は発生しない」と明記するかをユーザーに確認する。
- Fulmo の義務を増やす新しい期限・手続（買取代金の支払期限、買取希望の通知期限、報告の期日など）。判断時点が必要なら、原契約にすでにある期間を使う。
- 成果・売上・利益・順位・PV・CV・期日の保証や、保証と読める表現。
- 将来の延長・無償対応・再変更の約束。譲歩は「今回限りの特別措置」「上限」として書き、「予定」にとどめる。確約するかどうかは経営判断なので、ユーザーに確認する。
- 業務の量・頻度・期日の新しい約束（「毎月」「〇日以内に」「定例MTG」など）。量を書く必要があるときは「目安」「新規・リライトの合計」「当社の判断で配分」とし、未達時の扱いを決める。
- 非を認める表現（謝罪、「弊社の不手際で」）、「補填」「補償」という語。
- 証明できない事実（「営業から説明済み」など、記録で裏付けられない主張）。
- 依頼にない条件・論点（支払条件、違約金、規約の責任制限による反論など）。必要そうなら草案の外で提案する。

## 2. 書くことで Fulmo を守るもの

テンプレートや過去の書面に入っていれば引き継ぐ。新しく加えるときは、手塚さんのレビュー用メモで「追加した条項」として示す。
- 「本覚書に記載なき事項については原契約の規定が適用される」（覚書・合意書の締め）と、長い覚書では「本覚書と原契約が抵触する場合は本覚書が優先する」。
- 協議条項:「契約内容の変更・更新等については協議のもと決定する。」相手の要望で特例（短期更新など）を受けるときに入れ、相手に一方的に解約されない余地を残す。
- 清算条項:「本合意書に定めるもののほか、甲乙間に何らの債権債務がないことを確認する。」揉めた案件を終えるときや、原契約を切り替えるとき。支払いがある場合は「本件精算金全額の支払が完了したこと」をもって効力が生じる形にする。
- 買取（譲渡）を行わない場合: 未払金がある、重大な違反が是正されない、満了以外の事由で終了した。
- 知的財産権（Shoppal のシステムなど原契約で Fulmo に帰属するもの）は譲渡の対象に含まない。
- 無償にする範囲と、引き続き顧客が負担する費用（報酬金、受発注の利用料、商品原価、送料、決済手数料、ドメイン費用など）の列挙。金額は書かず原契約の条番号で参照する。
- 延長する場合は自動更新の扱い（適用しない、または終了日）を明記する。
- 減額に応じる場合は「契約満期まではその金額とする」と期間を区切る。
- 口外禁止を入れる場合は、行政機関・司法機関への法令に基づく相談・申告と、権利行使に必要な範囲の開示を例外にする（入れないと無効になるおそれがある）。

## 3. 相手方から条件を求められたとき

- 会社として受け入れられる文言なら取り込んでよい。範囲や制限の強さが論点になるもの、Fulmo の負担が増えるものは、草案に入れずユーザーに示す（求められている条件／入れた場合の影響／応じ方の案: 入れない・表現を弱める・上限を付ける・期間を区切る）。
- 譲歩するときは「契約論を超えた歩み寄り」として示し、一度出した数字と根拠は変えない。
- 相手の主張をそのまま受け入れたと読める書き方（相手の言う「売上」「保証」などの語をそのまま使う）を避け、原契約の文言で書く。

## 4. 書き方の注意（誤解と食い違いを防ぐ）

- 原契約の条番号を名指しする。規約の版によって条番号が違う（例: 譲渡は ver7 で第15条、v2.0 で第17条。Web 版の規約は 2025年6月1日改定版と 2026年7月以降の新規約で別）。必ずその顧客が締結した版の番号を使う。
- 定義語は原契約にそろえる。原契約にない社内用語（「買取保証」など）は使わず、原契約の文言（「本件譲渡」など）で定義する。同じものに2つの名前を付けない。
- 金額は税抜・税込を明記し、対象範囲（「2サイト合計で」など）まで書く。終了日・引渡し日・効力発生日は具体的な日付で書き、原契約と1日ずれていないか確かめる。
- 書面は目的の事項に絞る。前契約の内容を書き写さない（前契約を無効にするなら、別の簡易な覚書で「〇月〇日に締結した『（契約書名）』を無効にする」とする）。相手が強く反発している案件では条項を最小限にする。
- 当事者の表記は登記どおり（合同会社は「代表社員」）。Fulmo の住所は旧住所（恵比寿）を使わず、その顧客との直近の書面の表記にそろえる。
- 誤解や複数の解釈を生む言い回し（「特例として」の重ね書き、「寄り添う形」のような直接的すぎる表現、口語の「口頭合意のあった」など）を避ける。

## 5. 書き終えたときのチェックリスト

- [ ] 既存の契約（原契約・過去の覚書）と、当事者・日付・期間・金額・条番号・定義語が一致している
- [ ] 1章の「言及しない」事項が、本文にも送付文にも入っていない
- [ ] Fulmo の新しい義務・期限・保証が増えていない（増えている場合はユーザーの指示によるもので、レビュー用メモに書いた）
- [ ] 相手方に不利な条項があれば、レビュー用メモに「交渉で指摘されそうな点」として挙げた
- [ ] 確かめられなかった値は【●】の網掛けで、推測で埋めていない
- [ ] 先方に渡す版に社内メモ・注記・作成過程が残っていない
