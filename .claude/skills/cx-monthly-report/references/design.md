# デザイン規約（FIX版 2026-09 準拠）

キャンバスは 1920×1080px（PPTX書き出し時 13.33×7.5in、**pt ＝ px ÷ 2**）。値は `scripts/build_deck.py` の定数と一致させる。

## 色
| 用途 | 値 |
|---|---|
| 背景 | `#FFFFFF`（全スライド。グレー面・グラデーションは「AIっぽい」ため不可） |
| 本文・見出し | `#1A1A22` |
| 補足・注記 | `#33364A` |
| フッター・グレータグ | `#4A4F5E` |
| カード枠 | `#D5D8E2`（2px）／強調カード枠 `#4A3FB0`（3px） |
| アクセント（Fulmoパープル） | `#4A3FB0`（パンくず・区切り線・番号・強調バー・異動ブロック） |
| グラフの通常バー | `#B3ADE8`（強調する月だけ `#4A3FB0`） |
| ごく薄い面 | `#F4F3FC`（数式ボックス・KPIパネルだけ） |
| 肯定タグ／注意タグ | `#3F5FA6`／`#8A3F0A`（白文字） |
| 強調の赤 | `#E60000`（1スライド2か所まで。例：定義文、「←これが重要！」） |

ロゴは `assets/fulmo_logo.png`（ロゴのグラデーションは水色→紫。スライド側では再現しない）。

## 文字（Noto Sans JP のみ）
| 要素 | px | pt |
|---|---|---|
| 表紙タイトル | 132 | 66 |
| 表紙の上見出し／項目一覧 | 48／56 | 24／28 |
| パンくず（例：顧客対応 ｜ 請求） | 28 太字・紫 | 14 |
| タイトル（1メッセージ） | 48 太字 | 24 |
| カード見出し | 40 太字 | 20 |
| 本文 | **34** | **17** |
| 補足・数式 | 30 | 15 |
| 注記・✓ポイント・タグ | 28 | 14 |
| フッター・グラフ注 | 24 | 12 |
| KPIの大きな数字 | 96 | 48 |

24px未満は禁止。本文が収まらないときは文字を小さくせず、**文言を削る**か**2枚に分ける**。

## 共通レイアウト（本文スライド）
- 余白：上56・左右96・下112。右上にロゴ（180×58）。
- 上から：パンくず → タイトル（最大2行、幅1480）→ 紫の区切り線（4px）→ 本文 → フッター（左「© Fulmo Inc. All rights reserved」、右にページ番号）。
- 表紙：白地、左上ロゴ、上見出し、特大タイトル、紫の線、項目一覧。**左端の帯や下の社名行は付けない**（FIXで削除）。

## スライド型（build_deck.py の `type`）
| type | 使う場面 | 構成 |
|---|---|---|
| `cover` | 表紙 | eyebrow／title／agenda |
| `kpi_chart` | KPIの報告（NRRなど） | 左：「◯◯とは？」定義（赤で強調可）・数式ボックス・例・基準タグ（「←これが重要！」の赤い吹き出し可）。右：推移の棒グラフ（点線＝基準値、最新月を紫で強調）＋注記＋✓ポイント |
| `flow3` | 取り組みの経緯 | 背景 → 取り組み → 結果 の3カード＋矢印。最後のカードは紫枠、中に「⇒ 次の打ち手」 |
| `before_after_kpi` | 運用の変更 | 左：これまで → これから＋期待効果タグ。右：KPIパネル（状況タグ・大きな金額・※注記・⇒期日） |
| `grid4` | 仕組み化・施策の一覧 | 01〜04の番号付き2×2カード（見出し＋1〜2行） |
| `announcement` | 人事・体制 | 左：紫ブロック（「異動のお知らせ」、名前と異動先、温かい一言、任意で写真）。右：引き継ぎ方針 01〜03（任意でイラスト） |

同じ型を続けて使わない。6枚前後（表紙＋5）が標準。
