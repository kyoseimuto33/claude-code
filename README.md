# 収益シミュレーション — armtechstore.jp

ECサイト [armtechstore.jp](https://www.armtechstore.jp)（モニターアーム販売）の
月次レポートExcelに含まれる実績データ（2025/03〜2026/06）をもとに、
収益シミュレーションを実測ベースで再構築したものです。

## 成果物

| ファイル | 内容 |
|---|---|
| `output/収益シミュレーション_armtechstore_2026-07.xlsx` | **完成版シミュレーションExcel。** シナリオ・料金プランをドロップダウンで切り替えると全体が再計算されます（シミュレーション／シナリオ比較／モンテカルロ／実績データ／前提・根拠 の5シート） |
| `index.html` | **インタラクティブ収益シミュレーター。** ブラウザで開くだけで動作。成長率・CVR・単価・粗利率・料金プランをスライダーで変更でき、モンテカルロによるP10〜P90レンジがリアルタイムに再計算されます |
| `simulator/model.py` | 予測モデル本体（パラメータ推定・3シナリオ・モンテカルロ2万試行） |
| `simulator/generate_excel.py` | Excel生成スクリプト |
| `data/monthly_actuals.csv` | 月次実績（元Excelの各月次レポートシートから統合） |
| `data/keywords_2026-03.csv` | 追跡キーワード506件の検索Vol.と順位（2026年3月時点） |
| `output/simulation_results.json` | モデルの全出力（シナリオ別月次予測・P10/P50/P90・料金プラン別手残り） |

再生成: `pip install numpy openpyxl` のうえ `python3 simulator/model.py && python3 simulator/generate_excel.py`

## 元シミュレーションからの主な補正

元のシミュレーションシートは CVR 0.10%→0.15%・訪問数+10%/月 を仮定していましたが、
いずれも実測（CVR 95%信頼区間の上限0.093%、直近成長+2.0%/月）を大きく超えるため、
実測ベースの3シナリオに置き換えました。

| シナリオ | 成長率/月 | CVR | 単価 | 12ヶ月累計売上 | 12ヶ月累計粗利 |
|---|---|---|---|---|---|
| 保守 | +1.0% | 0.045% | ¥12,000 | ¥400,983 | ¥196,481 |
| 標準 | +2.5% | 0.065% | ¥14,000 | ¥745,947 | ¥365,514 |
| 強気 | +5.0% | 0.090% | ¥15,000 | ¥1,307,948 | ¥640,896 |

注文数が月3〜5件と少なくCVR推定の不確実性が大きいため、点推定に加えて
モンテカルロ（注文数〜Poisson、単価〜対数正規）による P10〜P90 レンジを併記しています。

### 料金プラン別 クライアント手残り（12ヶ月累計 = 粗利 − SEO費用）

| プラン ＼ シナリオ | 保守 | 標準 | 強気 |
|---|---|---|---|
| 現行: 月額55,000円 | −¥463,519 | −¥294,486 | −¥19,104 |
| 提案: 月額88,000円+売上5% | −¥879,569 | −¥727,782 | −¥480,502 |
| 希望: 粗利レベシェア50% | +¥98,240 | +¥182,756 | +¥320,448 |

固定費型プランは現状の粗利水準（月2〜6万円）では期間内の黒字化が難しく、
粗利連動型（レベシェア）は手残りが常に粗利の50%となりマイナスになりません。

## 注意事項

- 本数値は注文27件という限られた実績に基づく概算であり、月次の実売上はP10〜P90レンジ程度の振れが想定されます。
- 実際の推移は運営状況・季節性・外部環境等の影響を受けます。今後の方向性検討の材料としてご利用ください。
