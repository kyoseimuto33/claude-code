# armtechstore.jp 収益シミュレーション（2026年7月 改訂版）

ECサイト [armtechstore.jp](https://www.armtechstore.jp) の収益シミュレーションを、
2025/07〜2026/06の実績12ヶ月（Fulmo月次レポート）に基づいて再構築したものです。

## 成果物

| ファイル | 内容 |
|---|---|
| `armtechstore_収益シミュレーション_改訂版.xlsx` | 数式連動のExcelモデル。シート構成: ①シミュレーション（改訂版） ②前提条件・根拠 ③実績データ |
| `index.html` | ブラウザで開くだけで動くインタラクティブ・シミュレーター（外部依存なし）。スライダーで前提を変更すると即時再計算 |
| `build_simulation.py` | Excelファイルの生成スクリプト（openpyxl）。実績更新時に再実行して再生成可能 |

## モデル構造

```
サイト訪問数 = 前月訪問数 × (1 + 成長率)     … 起点は直近3ヶ月平均 5,877
注文数       = 訪問数 × CVR
売上         = 注文数 × 平均購入単価
粗利         = 売上 × 粗利率
純収支       = 粗利 − 月額費用
```

## 前提（実績からの導出）

| 項目 | 保守 | 標準 | 強気 | 実績根拠 |
|---|---|---|---|---|
| 訪問数成長率/月 | +2% | +5%→+3% | +8%→+5% | 直近4ヶ月は横ばい。KW上位化余地（「アーム モニター」検索Vol 74,000で49位 等）|
| CVR | 0.065%固定 | 0.070%→0.095% | 0.070%→0.120% | 直近6ヶ月平均 0.0651% / 直近3ヶ月 0.0737% / 月次最高 0.0863% |
| 平均購入単価 | ¥13,000 | ¥14,000 | ¥14,500 | 全期間加重平均 ¥14,141（27件） |
| 粗利率 | 47% | 49% | 50% | 全期間実績 49.0%（月次レンジ 45.6〜52.8%） |

## 結果（予測12ヶ月: 2026/07〜2027/06、月額費用55,000円）

| シナリオ | 累計売上 | 累計粗利 | 粗利>月額費用の到達月 | 累計（粗利−費用） |
|---|---|---|---|---|
| 保守 | ¥679,294 | ¥319,269 | 期間内なし | −¥340,731 |
| 標準 | ¥1,116,879 | ¥547,270 | 2027/04 | −¥112,730 |
| 強気 | ¥1,641,419 | ¥820,711 | 2026/11 | +¥160,711 |

3つの実装（Excel数式・Python・ブラウザJS）は丸め処理まで含めて同一の結果を返すことを検証済み。

## 旧シミュレーションからの主な修正点

1. 2026/07の売上が前月実績の固定値のまま数式と不整合だった点を修正（予測期間全体をモデル数式に統一）
2. CVR到達値 0.15% → 0.095%（実績月次最高0.086%に対して1.7倍は根拠不足のため）
3. 平均単価 ¥13,000 → ¥14,000（実績加重平均 ¥14,141）
4. 粗利 =売上÷2 → =売上×49%（実績粗利率）
5. 単一シナリオ → 3シナリオで不確実性を明示
6. 予測起点を単月値ではなく直近3ヶ月平均に変更（月次ノイズ除去）

## 精度に関する注意

月間注文数が0〜5件と少数のため、単月のCVR実績は0.041〜0.086%の範囲で大きく変動します。
本モデルは「単月の的中」ではなく「6〜12ヶ月累計の中心推計」として設計しており、
四半期ごとに実績でパラメータを更新することを推奨します。季節性は実績1年分では分離不能のため未考慮です。

# CX 月次活動報告の自動作成（Claude Code スキル）

全社会向けのCX月次報告を「調査 → 整理 → Fulmoカラーのスライド」まで同じ品質で作るための環境です。
このリポジトリで Claude Code を開き、`/cx-monthly-report` と入力するか「10月のCX活動を全社会向けにまとめて」と頼むと起動します。

| パス | 役割 |
|---|---|
| `.claude/skills/cx-monthly-report/SKILL.md` | 手順書（条件確認 → 並列調査 → チャットで整理 → 項目確定 → 数値の裏取り → 生成 → QA → 引き渡し） |
| `.claude/skills/cx-monthly-report/references/` | デザイン規約・文章ルール・調査手順・FIX版（2026年9月）から学んだこと |
| `.claude/skills/cx-monthly-report/scripts/build_deck.py` | `content.json` → Slidesアーティファクト用ファイルを生成（デザイン値はここの定数で一元管理） |
| `.claude/skills/cx-monthly-report/scripts/check_deck.py` | 文字サイズ・白背景・1枚1メッセージ・⇒次の打ち手・出典の有無を機械チェック |
| `.claude/skills/cx-monthly-report/examples/content.example.json` | スライド内容のひな形（6種類のスライド型） |
| `.claude/agents/cx-report-researcher.md` | 調査サブエージェント（Slack担当・Drive担当を並列起動。読み取りのみ） |
| `.claude/agents/cx-deck-reviewer.md` | レビューサブエージェント（事実の裏付け・機密混入・読みやすさを確認） |

このリポジトリは公開設定のため、顧客名・金額・シートIDなどの社内データは含めていません。実データは実行時にSlack・Driveから取得します。
