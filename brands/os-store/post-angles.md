# os-store 投稿の切り口アイデア（Claude Code提案）

フォームの「投稿の切り口」が空欄だったため、ターゲット（30〜50代・実用重視・キャッシュレス/荷物を減らしたい層）と推しポイントから提案。

## 1. 身軽に出かける提案
- カードポケットにICカード・クレカを入れて「スマホ1つでお出かけ」
- 近所の買い物・ランチ・散歩など、財布を持たないシーン描写
- → ターゲットのライフスタイル（キャッシュレス・荷物を減らしたい）に直結

## 2. 失敗しない選び方
- ベルト（留め具）あり／なしの違い
- カード収納枚数・ミラーの有無・スタンド機能
- 素材の選び方（レザー調・布・PU）
- → 保存されやすい「教科書型」コンテンツ。CTA「保存して見返してね」と好相性

## 3. デザインテイスト別紹介
- 大人シンプル／花柄・くすみカラー／レザー調・ビジネス向け など
- → 訴求の柱「様々なデザインを取り揃えている」に直結

## 4. お悩み解決
- 「画面割れが心配」→ 全面を覆う手帳型の保護力
- 「カードを持ち歩きたい」「動画を見るとき立てたい」→ 機能で解決
- 「手帳型は分厚い？」→ 薄型・軽量タイプの紹介
- → 実用重視のターゲットに刺さる

## 5. 機種別特集
- iPhone新機種発売時の対応ケース特集、Android人気機種特集
- → 訴求の柱「機種別に探せる」に直結。新機種発売はタイムリーな投稿機会

## 6. 買い替えタイミング
- 機種変更したとき／ケースの角がへたってきたとき／季節・気分で衣替え
- 「ケースも消耗品」という気づきで購入動機をつくる

## 運用メモ
- トーンは「落ち着いた・女性らしい」— 上品な配色、丁寧な語りかけ
- 価格訴求よりデザイン・機能・探しやすさを優先
- 締めは既定CTA「保存して見返してね」
